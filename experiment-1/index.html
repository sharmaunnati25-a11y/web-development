Experiment 1: Git Version Control & GitHub Pages Hosting

Student: Unnati Sharma | B.Tech CSE (Data Science)

Aim & Objectives

To initialize a local Git repository, create isolated feature branches for each web development module, commit source files, merge feature branches into the main production branch, push the codebase to GitHub, and configure automated static site hosting using GitHub Pages.

Branching Strategy
Separate feature branches for each experiment merged into main.
GitHub Pages
Direct deployment of static assets from the root / directory.

Sequential Git Execution Log

1 Initialize Git & Set User Identity

Initialize the local repository and configure commit attribution.

# Initialize repository in current root directory
git init

# Configure user credentials
git config user.name "Unnati Sharma"
git config user.email "your.email@example.com"

2 Create & Switch to Feature Branch

Create isolated branches for each experiment before merging.

# Create and switch to feature-portfolio
git checkout -b feature-portfolio

# Stage and commit experiment 2 files
git add experiment-2/
git commit -m "feat(exp2): implement personal portfolio for Unnati Sharma"

3 Merge Feature Branches into Main

Switch back to main and integrate feature branches cleanly.

# Ensure default branch is main
git branch -M main

# Merge feature branch
git merge feature-portfolio -m "merge: integrate feature-portfolio into main"

# Stage all remaining experiments
git add .
git commit -m "feat: complete all 6 web development laboratory experiments"

4 Link Remote Repository & Push

Add your GitHub remote repository origin and push the main branch.

# Link remote repository (replace with your repo name)
git remote add origin https://github.com/sharmaunnati25-a11y/web-development.git

# Push main branch to remote
git push -u origin main

5 Deploy to GitHub Pages

Enable GitHub Pages hosting via Repository Settings.

  1. Navigate to your GitHub repository: https://github.com/sharmaunnati25-a11y/web-development
  2. Click on the Settings tab at the top.
  3. In the left sidebar, click on Pages.
  4. Under Build and deployment > Branch, select main and folder / (root).
  5. Click Save. In 1–2 minutes, your website is live at:
    https://sharmaunnati25-a11y.github.io/web-development/
Git Lab Verification Checklist
  • Git Repository Initialized (git init)
  • Working tree clean & tracked (git status)
  • Feature branches created & merged (git branch)
  • Commit history structured with clear messages
  • GitHub remote origin mapped (git remote -v)
  • GitHub Pages static hosting active
