## Summary of Experiments

| Experiment | Title | Description & Core Technologies |
|---|---|---|
| **Experiment 1** | Git Version Control & GitHub Pages | Git initialization, feature branching, merging, remote push, and GitHub Pages static hosting. |
| **Experiment 2** | Personal Portfolio Webpage | Portfolio for Unnati Sharma featuring About, Skills (learned vs. learning), Projects, Education, and Contact form. |
| **Experiment 3** | Dynamic To-Do List Application | DOM manipulation, task creation, strike-through completion, deletion, priority tagging, filtering, and LocalStorage. |
| **Experiment 4** | Webpage SEO & Accessibility | Semantic HTML5, single `<h1>` hierarchy, meta tags, Open Graph, Twitter Cards, JSON-LD Schema, WCAG 2.1 AA keyboard navigation. |
| **Experiment 5** | Real-Time Weather Application | Asynchronous JavaScript (Fetch API), real-time weather retrieval via Open-Meteo, temperature, conditions, 3-day forecast. |
| **Experiment 6** | Responsive Blog Website | Multi-device layout adapting across mobile, tablet, and desktop using Bootstrap grid and custom CSS3 `@media` queries. |
